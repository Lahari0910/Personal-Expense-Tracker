# Personal Expense Tracker

A simple Python-based expense tracking application that allows users to add, view, and analyze their personal expenses.

## Features

- Add new expenses
- View all expenses
- Calculate total spending
- Find highest expense
- View category-wise spending
- Save expenses to CSV
- Load saved expenses when the program starts
- Standardize expense categories

## Technologies Used

- Python
- CSV File Handling

## Python Concepts Used

- Variables
- Lists
- Tuples
- Dictionaries
- Loops
- Conditional statements
- User input
- Functions and built-in functions
- File handling
- CSV processing
- `csv.DictReader`
- `csv.writer`
- `max()`
- `sum()`

## Example Categories

- Food
- Travel
- Shopping
- Bills
